# Compatibility

| Jar | Minecraft | Loader | Refined Storage | Java |
|-----|-----------|--------|-----------------|------|
| `rspolymorph-neoforge-1.21.1-<version>.jar` | 1.21.1 | NeoForge 21.1.219+ | 2.x (tested 2.0.8) | 21 |
| `rspolymorph-fabric-1.21.1-<version>.jar` | 1.21.1 | Fabric Loader 0.16.10+ and Fabric API | 2.x (tested 2.0.8) | 21 |
| `rspolymorph-neoforge-26.1.2-<version>.jar` | 26.1.2 | NeoForge 26.1.2.x | 3.x (tested 3.2.0) | 25 |

- **Polymorph is not needed**: recipe selection is built in.
- **Install on both sides**: the client draws the button and the popup, the server applies the
  choice and resolves patterns during autocrafting.
- **Optional**: Refined Storage - Quartz Arsenal 1.0.7 or later, for its Wireless Crafting Grid.
- **Fabric on 26.1.2** is implemented but not built yet: it waits for a stable Fabric Loom with
  Minecraft 26.x support ([issue #5](https://github.com/Team-Arcadia/mods-mc-rspolymorph/issues/5)).
